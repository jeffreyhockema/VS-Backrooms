# Graphics pass: decisions per family

The user's call, family by family, on what each batch changed. Each row links its before | after image, made by
`tools/shotbot/sidebyside.py` from `docs/design/graphics-pass/sidebyside/<batch>.json`. `review/compare.html` shows them
all on one page. `review/` is git-ignored, so the images exist only on the machine where the batch was shot. Fill in the
decision column with keep, revert or tweak. A revert restores that family's generator function from `main`, and the
note says which function that is.

| family | batch | side-by-side image | decision (keep / revert / tweak) | note |
|---|---|---|---|---|
| Chevron wallpaper (all parts, damp) | B3 | review/b3/sidebyside/wallpaper.jpg | | Printed paper (`gen_textures.paper_wall`, `motif_chevron`): fibre, faint strip seams. The chevron prints darker than before (`CHEVRON_PRINT`, about 48 levels below the paper instead of 34), so it reads from a few blocks away; the beads print at half strength. Three versions per part: base, `-2`, `-damp`. The damp version keeps its stain inside the block. |
| Other papers (pale arch paper, manila; dotted and stripped are not in any shot) | B3 | review/b3/sidebyside/other-papers.jpg | | Same paper build. Manila had 5 px dots that did not tile; it now has a 4 px dot and fainter seams. Stripped is now drywall with paste bands, and paper scraps appear in one version of three. Dotted only generates in worlds from before layout v4. |
| Baseboard, chair rail, outlet | B3 | review/b3/sidebyside/trims-outlet.jpg | | `add_baseboard`, `add_rail` and `add_outlet`: a lit cap and a dark toe, a scuff band above the trim, and a smaller 5 x 7 px outlet with a bevel and a shadow. The outlet is still painted: as a modelled outlet the wall block would no longer be a plain cube, which changes how it is lit and drawn. |
| Carpet (normal) | B3 | review/b3/sidebyside/carpet.jpg | | `gen_textures.carpet`: a beige Berber loop pile from `matlib.carpet`, colour kept. Two seeds at the same mean brightness, each turned at random (`carpet.json` alternates). |

Threadbare is a jute backing with tuft rows; the old one used a 3 px grid that did not tile. |

The sides, seen where the ceiling layer ends, have a cut-edge texture of their own (`ceilingtile-side`). |
