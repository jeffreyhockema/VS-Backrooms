# Design notes

These are the working documents the mod was built from: design plans, research briefs and review notes, kept as a record of why things are the way they are. They were written during development and are historical: they are not kept up to date. Where one disagrees with the code, the code wins. For how the mod plays now, read the [player guide](../GUIDE.md); for how the code is laid out, read [DEVELOPING.md](../DEVELOPING.md).

They contain spoilers for every level.
